# Notes: Sprint task structure

- Based on the owner's sprint proposal (2026-10-31), with three changes:
  1. A sprint is a part of one milestone. `PRODUCT.md` still sets the scope.
  2. Agent rules are in `AGENTS.md`. `tasks/index.md` describes only the
     layout and the steps.
  3. No velocity numbers. The retrospective is short and has lessons.
- Sprints have a start date and no fixed length.
- No per-sprint `completed.md`. `sprint.md` lists the done tasks.
- The legacy table in `archive/tasks-legacy.md` has duplicate IDs (23 and 24).
  It is kept without changes as history.
